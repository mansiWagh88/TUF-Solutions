## 📝 Problem Statement

You are given a sorted array of integers **arr** and an integer **target** . Your task is to determine how many times target appears in arr.

Return the **count of occurrences of target** in the array.

### Example 1

<p>

**Input:** arr = [0, 0, 1, 1, 1, 2, 3], target = 1</p><p>

**Output:** 3</p><p>

**Explanation:** The number 1 appears 3 times in the array.</p>

### Example 2

<p>

**Input:** arr = [5, 5, 5, 5, 5, 5], target = 5</p><p>

**Output:** 6</p><p>

**Explanation:** All elements in the array are 5, so the target appears 6 times.</p>

### Example 3

<p>

**Input:** arr = [2, 4, 6, 8, 10], target = 3</p>Output:

0

### Constraints

- 1 <= arr.length <= 10^6
- 1 <= arr[i] <= 10^6
- 1 <= target <= 10^6

- **Space Complexity:** $\mathcal{O}(1)$
